Public Data Exports & MCP Server

Footfall publishes daily precomputed Parquet datasets, JSON profile files, shields.io badges, and a stateless Model Context Protocol (MCP) server for autonomous agents.

License: CC BY 4.0 Format: Apache Parquet & JSON Transport: Streamable HTTP Dictionary: docs/data-dictionary.md

1. Connecting via Model Context Protocol (MCP)

Add Footfall to your AI agent environment (Claude Code, Claude Desktop, Cursor) to give it real-time access to empirical adoption data:

{
  "mcpServers": {
    "footfall": {
      "command": "uvx",
      "args": ["footfall", "serve", "--stdio"]
    }
  }
}

Available Read-Only Tools

  • footfall_compare: Compare 2 to 6 tools side-by-side with adoption z-scores and divergence.
  • footfall_trend: Weekly time-series lookback (4 to 104 weeks) for a single tool.
  • footfall_find_rising: Discover accelerating tools filtered by category and lifecycle phase.

3. Shields.io Maintainer Badges

Show your verified Footfall adoption status on your project README:

[![Footfall](https://img.shields.io/endpoint?url=https://data.footfall.dev/v1/badges/langgraph.json)](https://footfall.dev/entity.html?id=langgraph)

*Note: In accordance with our positive badges rule, maintainer badges only display positive milestone phases (breakout, use_ahead, emerging, mainstream). Non-accelerating phases display a neutral grey tracked status.
